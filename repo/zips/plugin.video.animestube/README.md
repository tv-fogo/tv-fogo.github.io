# Animes Online para Kodi

## Requisitos

- Kodi 21.3 ou posterior, com a API `xbmc.python` 3.0.1.
- O Python é fornecido pelo Kodi. O código é compatível com Python 3 e não fixa uma versão patch como 3.14.7.
- `ResolveURL` é opcional e usado para embeds de provedores diferentes do Blogger.

## Recursos

- Episódios recentes, lista de animes, gêneros e pesquisa.
- Link "Próxima página" nas categorias em que o site oferece avanço.
- Resolução preferida dos vídeos Blogger selecionável, até a máxima disponível.
- Reprodução de fontes diretas, resolução própria de embeds Blogger e suporte opcional ao ResolveURL para outros players.
- Validação de domínio e bloqueio de redirecionamentos para outros hosts durante a navegação.

As configurações permitem escolher a qualidade máxima desejada para vídeos Blogger e ativar ou desativar o ResolveURL para outros provedores. A disponibilidade de cada resolução depende do vídeo hospedado e dos hosts suportados pela versão instalada do ResolveURL.

## Instalação manual

1. Compacte o conteúdo do addon em uma pasta cujo nome corresponda ao ID `plugin.video.anitube`.
2. No Kodi, abra **Add-ons** e escolha **Instalar a partir de um ficheiro ZIP**.
3. Selecione o ZIP criado.

Use este addon somente com conteúdo que você tenha autorização para acessar.
