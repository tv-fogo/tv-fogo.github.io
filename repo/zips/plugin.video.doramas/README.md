# Seu Dorama para Kodi

## Requisitos

- Kodi 21.3 ou posterior, com a API `xbmc.python` 3.0.1.
- O Python é fornecido pelo Kodi; o addon é compatível com Python 3.
- `ResolveURL` é opcional e necessário para resolver alguns players hospedados.

## Recursos

- Episódios recentes, catálogo de doramas, gêneros e pesquisa.
- Navegação pelas páginas do catálogo e dos gêneros até a última página disponível.
- Reprodução por fontes diretas ou escolha entre Servidor 01, Servidor 02, Servidor 03 e Alternativo.
- Tentativa de outras fontes quando o player escolhido não estiver disponível.
- Validação do domínio do catálogo e bloqueio de redirecionamentos externos durante a navegação.

Para usar players que dependem do ResolveURL, instale e habilite esse complemento no Kodi. A configuração de qualidade se aplica somente a vídeos Blogger, quando disponíveis.
